# AnabolicWorkoutTracker
AnabolicWorkoutTracker is primarily a Desktop application  that can be used to log workouts, view training data powered through data visualization libraries, and auto recomend lifting based on user defined templates. Users will be able to pick a program for the runtime and process of an application, such as 5/3/1, and have custom logging for each.

When a user selects a program, such as 5/3/1, or GZCL etc. The user will be prompted to input their maxes. These
maxes are convereted into 'training maxes' that the programs run on. Users will be able to upload
logs to this system, and the 5/3/1 program will be updated occordingly.

Users will be able to see past lifts, and all of the details surrounding that in Lift_Details. Aside from this detailed view, users will also be able to track their progress through data visualziaton of as many metrics as users could be curious for. Users will be able to see their progress in a specific lfit over time, they will be able to see volume over time, raw lbs/kg lifted, etc.

Not only for this, but users will all input a custom profile that has information such as their height, and weight. This information will be used to 'rank' users against others and apart of a global database where users will see what percentile their lfits fall on.
